A recall alert cannot inspect a stockroom. Lotline helps clinic operations teams turn a reviewed medical-device recall notice into an accountable stock response.

Created by Shivam Gupta.
Source code and Firebase deployment: https://github.com/shi1720/lotline-hack2heal

In this walkthrough:
• Email sign-in and a separate workspace for your own inventory
• CSV stock import and human-reviewed recall scope
• Missing lot numbers that stay unresolved until verified
• Quantity-controlled quarantine and permitted supplier return
• Completion review, activity history, and JSON/CSV/printable evidence
• Responsive desktop and mobile workflows

This is an actual application recording using Firebase emulators and fictional stock, locations, notices, receipts, and actions. No patient data or physical handling is shown. Narration is a neutral synthetic voice; subtitles are included.

Lotline supports unused medical-device inventory and operator-attested response records. It does not provide clinical advice, certify product safety, or terminate a regulatory recall. The source notice and real-world actions require human verification.
